# Bound By Brush

Dive into colorful artworks to fight against evil demons. Follow the adventure of **Iris**, after the Devil himself traps her inside dangerous art pieces. With your help — and a friend she makes along the way — will she be able to escape?

---

## 🎮 About the Game

**Bound By Brush** is a top-down action game built around a **color-matching combat loop**: every enemy belongs to a color, and the only way to defeat them is to **shoot them with the same color**.

As Iris travels through a series of cursed paintings, the story unfolds level by level — exploring themes of **redemption** and **staying true to yourself**, even when the world is trying to repaint you into something else.

---

## ✨ Key Features

- **Color Wheel Combat**
  - You have a rotating **color wheel**.
  - **Defeating an enemy advances you to the next color.**
  - Enemies can only be defeated by **shooting them with their own color**.
- **Progressive story across multiple levels**
  - Narrative develops through the journey across different artworks.
- **Modular code design**
  - The project is structured to make changes and extensions **easy and clean**.
- **Made with Godot**
  - Developed using the **Godot Engine**.
- **Localization**
  - Available in **English**, **Galician** and **Spanish**.
  - More languages are planned for future updates.

## 🕹️ Controls

### PC

- **WASD** — Move
- **Left Click** — Shoot

### Mobile

- **Joystick** — Move
- **Touching the screen elsewhere** — Shoot
 
> **Note:** Color switching is **no longer** done with the space bar.  
> Your color changes **only when you defeat an enemy** (advancing to the next color on the wheel).

---

## 🧠 How the Color System Works

1. You start with a color from the wheel.
2. Each enemy has a specific color.
3. **Match your shot color to the enemy color** to defeat them.
4. When you defeat an enemy, your current color **automatically rotates to the next color**.

This creates a constant decision loop: target selection, positioning, and timing — because the “right” enemy depends on the color you currently have.

---

## 🧩 Project Philosophy (Modular Design)

The codebase is designed with modularity in mind so that:
- adding new enemy types,
- tweaking the color wheel rules,
- adjusting shooting behavior,
- or expanding levels and interactions

…can be done without rewriting everything.

## 🚀 Running the Project (Godot)

To try the game, you just have to download and execute the newest file form the **releases** folder (.exe for Windows, .apk for android).

If you instead want to **compile from the source code**, the steps are the following:

1. Install **Godot Engine**.
2. Open the project folder in Godot.
3. Press **Play** to run.
